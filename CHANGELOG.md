# Changelog

## 1.0.0

- Initial release
- Freehand pen, highlighter, and eraser tools
- Shape drawing: rect, circle, diamond, arrow, line, triangle
- Text tool with click-to-place
- Sticky notes with color picker
- Code cards with file injection
- Infinite canvas with pan and zoom
- Undo/redo (60-step history)
- PNG export
- Auto-save across sessions
- VS Code theme sync (dark/light)
- Keyboard shortcuts for all tools
